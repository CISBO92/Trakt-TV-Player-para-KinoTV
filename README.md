# Trakt TV Player para Kino TV

Este complemento integra la base de datos global de **Trakt.tv** dentro de la aplicación multimedia Kino TV (v0.9.43), permitiendo buscar contenidos y reproducir películas o series de televisión utilizando servidores de streaming compatibles.

## 🚀 Características
- **Búsqueda Eficiente:** Conexión directa a los servidores de Trakt.tv.
- **Enriquecimiento Automático:** Vinculación de metadatos nativa para renderizar elencos de actores y trailers oficiales.
- **Resolución Avanzada:** Enrutamiento directo al servidor `vidsrc.to`.

## 🛠️ Instalación en Kino TV
1. Copia la URL de este repositorio de GitHub.
2. Abre la aplicación **Kino TV** en tu dispositivo Android.
3. Dirígete a **Ajustes ▸ Plugins**.
4. Presiona el botón **`+`**, pega la URL de este repositorio y selecciona **Agregar**.
